# Omarchy Marketplace publishing

The plugin is prepared for the official community marketplace workflow.

## Final owner checklist

- The repository is public and owned by the submitter.
- `manifest.json` remains at the repository root and `omarchy plugin validate .` passes.
- `README.md`, `LICENSE`, `SECURITY.md`, `THIRD_PARTY_NOTICES.md`, and `preview.png` are current.
- Installation, update, removal, and provider sign-in instructions were tested on Omarchy.
- No credentials, account identity, or real provider response is committed.

## Submit

1. Open the official [Publish a Plugin](https://plugins.omarchy.org/publish.html) page.
2. Choose **Submit Plugin** to open the marketplace repository's issue form.
3. Enter `https://github.com/Bappoz/omarchy-ai-usage` as the repository.
4. Choose the **AI** category and 1–3 accurate tags such as `ai`, `usage`, and `quickshell` if offered.
5. Review the generated issue, confirm the ownership/checklist statements, and submit it.
6. Keep the referenced commit unchanged while automated validation and maintainer review run. If a fix is needed, push it and follow the issue's revalidation instructions.

Approval is not automatic: marketplace automation scans the exact submitted commit and a maintainer makes the final decision.
